CompanyCam is the go-to photo documentation tool for roofing contractors and general contractors — used to capture before/after shots, safety documentation, and final project photos. It's not a CRM and doesn't have native review features, but its project completion events are a natural trigger point for a review request workflow.

This guide explains how to build a review request automation using CompanyCam, Zapier, and an SMS platform, why CompanyCam's completion event is a particularly strong trigger for roofers, and how ReviewShield fits into the picture.

## Why CompanyCam project completion is a strong review trigger

Most CRM-based review request triggers fire when a job status changes — which can happen prematurely (a tech marks "complete" before the final walkthrough) or with significant variance across job types. CompanyCam's project-complete event is different: it fires when documentation is finalized, which for roofing contractors specifically means:

- Before/after photos are uploaded
- Final quality inspection images are captured
- The customer photo set is ready to share

This is closer to actual completion than a job status update and closer to the moment of peak homeowner satisfaction than an invoice event. For roofers especially, building the review request off CompanyCam completion rather than CRM status creates a tighter relationship between "job is demonstrably done" and "ask the homeowner for a review."

## Building the CompanyCam → Zapier → Twilio workflow

**What you need:**
- CompanyCam (any paid plan)
- Zapier paid plan (needed for multi-step Zaps, $20–$50/month)
- Twilio account (SMS platform, pay-per-message — very low cost)
- Your Google review link (short URL from your GBP dashboard)

**Step 1: Create a Zapier account and connect CompanyCam**

In Zapier, search for CompanyCam as an app. Authenticate with your CompanyCam credentials. Test the connection.

**Step 2: Set the trigger**

Trigger: CompanyCam → "Project Status Updated"
Filter: Status = "Complete" (or the equivalent in your CompanyCam workflow)

**Step 3: Add a delay step**

Add a Zapier "Delay" step: 24 hours. This ensures the review request doesn't fire immediately at project close, giving the homeowner time to settle before receiving the ask.

**Step 4: Add the SMS send action**

Action: Twilio → "Send SMS Message"
To: {{project.customer_phone}} (pulled from CompanyCam project record — ensure phone numbers are captured in your projects)
From: Your Twilio number
Body:
```
Hi {{project.customer_name}}, thanks for letting us document the work at your place today.
If we did right by you, a quick Google review helps us a ton: [YOUR_SHORT_REVIEW_LINK]
— [Your Name], [Company Name]
```

**Step 5: Optional — add a follow-up Zap**

If you want a follow-up message after 4–5 days, create a second Zap that triggers from the same CompanyCam event, with a 5-day delay, and sends a follow-up SMS.

**Step 6: Test the full workflow**

Update a real (or test) project to "Complete" in CompanyCam and watch the Zap fire. Verify the SMS arrives with the correct link and personalization.

## What to capture in CompanyCam for review verification

CompanyCam is also a valuable evidence tool when you need to challenge a suspicious review. For every project, ensure you're capturing:

- **Before and after photos** with timestamps
- **Final walkthrough photos** showing completed work
- **Customer sign-off** (if you use CompanyCam's digital forms feature)
- **Project address** matching the job

When a suspicious review appears, CompanyCam's timestamped project records can confirm when work was completed at a specific address — which is evidence that a review claiming otherwise is inaccurate.

## Alternative: CompanyCam → Zapier → Review Platform

If you use a dedicated review platform (NiceJob, Podium, Birdeye) in addition to CompanyCam, you can use Zapier to trigger a review request through that platform instead of directly via Twilio. The workflow:

CompanyCam project complete → Zapier → [Review Platform] → review request fires using the platform's native sequence

This approach uses the platform's follow-up logic and reporting rather than building it manually in Zapier, but requires both tools to be paid.
